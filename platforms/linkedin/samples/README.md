# LinkedIn samples

SV's own LinkedIn posts, kept as evidence of SV's voice. The skill reads up to three samples closest in type to the task before writing or editing, and the retro loop learns from every new one.

One file per post, named `YYYY-MM-DD_short-slug.md`. Start each file with this header, then paste the post exactly as published:

```
---
date: 2026-10-04
type: case study | opinion | journey | motivation | offer | other
language: English | Hinglish
why_it_works: optional, one line from SV
results: optional, such as impressions, comments, DMs or clients
---
```

Rules:

1. Never edit a sample after saving it, not even to remove dashes. It records how SV actually wrote.
2. The validator skips this folder, so samples may contain anything SV wrote.
3. This repository is public, so add only posts SV has already published.
